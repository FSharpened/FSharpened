# Branding

| File | Use |
|---|---|
| `mark.svg` | App/package icon, avatar, favicon source (full colour, rounded tile) |
| `mark-mono.svg` | One-colour mark (`currentColor`) for docs, badges, dark/light UIs |
| `logo-horizontal.svg` | Mark + wordmark lockup (set in `currentColor`; wordmark uses Inter, falls back to system UI) |

**Concept.** An **F** whose arms are cut to a sharp diagonal (sharpened) plus a cyan diamond (the extension riding alongside the compiler, not forking it). It reads at 16 px, survives one colour, and scales to a tile, a favicon or a banner.

**Colour.** Indigo `#4338CA` to `#1E1B4B`, white `#FFFFFF`, accent cyan `#22D3EE`. **Clear space:** at least the diamond's width on every side. **Minimum size:** 16 px (mark), 120 px wide (lockup). Do not recolour the accent, rotate, outline or stretch the mark.
