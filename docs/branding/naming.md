# Naming and Branding

One canonical slug for machines, two display forms for humans.

| Surface | Use | Never use |
|---|---|---|
| Repo / org / URL | `fsharpened` | `f#ened`, `f-sharpened` |
| NuGet ids, .NET namespaces | `FSharpened.*` | `F#ened.*` (`#` illegal) |
| dotnet tool | `fsh` (long form `fsharpened`) | `f#` |
| Prose / README | **FSharpened** | F#ened |
| Logotype / sticker | **F#ened** | FSharpened in a logo |
| File names, Docker tags, config keys | `fsharpened` | anything containing `#` |

Tagline: *Sharpen your existing F#.* README first line must state it is not a fork, not a compiler patch, not a new language.
Standard disclaimer (every package README): *FSharpened is an independent community project. It is not affiliated with, endorsed by, or a replacement for Microsoft's F# compiler or the F# Software Foundation.*
Logo direction: the `#` as a whetstone/honing stroke on an existing blade. Assets (`wordmark.svg`, `logotype.svg`) are not yet created.
