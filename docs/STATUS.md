Not verified: other RIDs, musl, NativeAOT of a program that binds a Rust library. See `docs/operations/rust.md`.

- `FSharpened.Diagnostics` - `StructuredDiagnostic` model only.
- `FSharpened.Effects` - `Effect<'T,'E>` struct and map/bind; no `effect { }` CE.
- `FSharpened.ML.Portability` - contracts for TorchSharp and ONNX Runtime (draft).
- `FSharpened.ML.Hardware` - resolver and default inference chain; availability probe is injected, not real.
- `FSharpened.Models` - five-layer fallback runner; no models.
- `fsh` CLI - help text and `doctor` (runtime identity only).

Not run: the other five RIDs.
- **Verified in the browser pane** on the built site served from localhost (not the live origin): the editor menu and a submenu action; the tree, tab, project and output menus (keyboard walk and Enter, Duplicate, Close Others, a disabled item); Shift+right-click leaving the browser's menu; a keyboard-invoked menu (dispatched events, not a real Menu key); palette fuzzy search and recents; project search; the settings dialog with a live theme change; snippet completion with tab stops; Ctrl+D with typing over three cursors and undo; outline jump with breadcrumb; the status bar's go to line, indentation and line-ending pickers, and a CRLF round trip through the saved project; the shortcuts dialog; layouts at 375 px (no horizontal overflow), 611 px (sidebar drawer) and about 1100 px; imports through a simulated file input.

Designed only (ADR-0022): language-server bridge, FSharpened as a VS Code extension, an AI completion provider (PLAN P7.4 to P7.6).

- **Verified locally on 2026-11-16** by running the Worker with `wrangler dev` and the compiled F# core against the real services: all 34 starter programs ran and produced output through Compiler Explorer and Wandbox, and each of 16 languages was checked with a runtime error and a compile error (the error became a Problems entry with line and column, except where the tool gives none: R, TypeScript at run time, OCaml runtime, C `abort`). In the browser pane: all 18 tabs switch with their own highlighting, compilers and examples, a Python NameError became a marker on the right line, PHP ran, and the tab strip scrolls at phone width. Not verified on the live origin beyond those two requests, in other browsers, or on a real phone.
- F# core (`tools/FSharpened.Ide`, 46 xunit tests) is compiled by Fable and reused by the page; the compiled core is also run against captured compiler output by 9 Node tests (`ide/web/test`), because .NET and JavaScript regular expressions differ; the gateway has 28 tests. Verified on win-x64 only; the `ide` workflow builds and tests it on ubuntu but has not run.
- Limits: depends on the public APIs of Compiler Explorer and Wandbox (ADR-0018, ADR-0020); Wandbox answers HTTP 429 after a short burst, which the gateway reports as "busy, try again"; 12 runs/min/client; short execution caps. Kotlin and Julia are excluded because their error paths are unusable on Compiler Explorer (ADR-0020). Wandbox serves one compiler for TypeScript and R, so a failure there falls straight to offline checks. Not yet done: in-browser F# language service (hover/completion beyond keywords), multi-file projects.
