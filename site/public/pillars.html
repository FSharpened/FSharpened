Pillars

28 independently versioned packages plus tools, declared in registry/pillars.json.

P0SubstrateStable

Cross-platform abstraction

FSharpened.Platform

Owns every OS-specific behaviour behind interfaces and a capability manifest: file watching, IPC transport, path identity, overlay store, sandboxing, terminal, runtime identity. Nothing else may #if on a platform.

P0SubstrateStable

Snapshot / fork / rollback / merge substrate

FSharpened.Statepoints

Shared statepoint graph used by hot reload, debugging, model canarying, experiment tracking and chaos testing. No component may implement its own checkpointing.

P1SubstratePreview

Semantic grounding for agents (MCP + library)

FSharpened.Semantic

find / check / types / rename / dead-code plus model-aware queries, exposed as a library and a stdio MCP server. Agents must use it for symbol resolution.

Wraps: FsLangMCP, SageFs, FsAutoComplete

P0ProductStable

Wraps: FSharp.Compiler.Service
