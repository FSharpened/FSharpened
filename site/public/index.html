What you get

Six principles shape every pillar.

Not a fork

Zero changes to the F# compiler. Every capability routes through FSharp.Compiler.Service, the analyzers SDK, NuGet or LSP. When F# ships a fix, you get it for free.

Everywhere, first-class

Windows, Linux and macOS on x64 and arm64 are equal citizens. No component is privileged; platform behaviour lives in exactly one pillar.

Rollback is a primitive

Statepoints give every tool one way to snapshot, fork, roll back and merge state. Hot reload, AI edits and training all use the same substrate.

Agents-ready by design

Semantic grounding over MCP, deterministic fallbacks and machine-checked invariants, so agents and humans maintain it side by side.

Trustworthy ML

ONNX-first inference, signed model cards, frozen judges and a five-layer fallback chain. Models never bypass telemetry, security or statepoints.

Compose, don't rebuild

Fantomas, FSharp.Analyzers.SDK, netcoredbg, Ionide: we wrap and connect the best tools instead of competing with them.

Try the CLI

The fsh command line is the front door. Today it ships doctor; the rest of the surface is on the roadmap.

git clone https://github.com/FSharpened/FSharpened.git
cd FSharpened
python tools/ci/fsh_ci.py run      # the same pipeline CI runs
dotnet run --project tools/FSharpened.Cli -- doctor
