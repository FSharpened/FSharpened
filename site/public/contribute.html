Contribute

Built by humans and agents together, governed by written rules.

Set up

Install the .NET SDK 9.0.200+ and Python 3, then run python tools/ci/fsh_ci.py install-hooks.

Pick work

Choose an item from the TODO, branch as feat/<pillar>-<short>.

Follow the order

ADR, canonical doc, contract tests, implementation, platform matrix, docs map.

Open a PR

Say which RIDs you could not verify. A reviewer other than the author approves; merging is human-gated.

Security issues: please do not open a public issue, see SECURITY.md.
